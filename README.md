# 🏥 Child Health Tracker – C++ Clinic Management System

## 📌 Project Overview
The Child Health Tracker is a console-based C++ application designed to manage and monitor children's healthcare records in a clinic environment. The system supports registration of users (children, doctors, and nurses), captures medical records such as vaccinations and medications, and maintains a complete history of consultations.

It is built to improve efficiency, accuracy, and accountability in managing pediatric health data.

---

## 🚀 Features

### 👤 User Management
- Register users (Child, Doctor, Nurse)
- Secure login system
- Role-based access control
- Automatic unique Child ID generation

### 💉 Medical Records
- Capture vaccination records
- Capture medication records
- Store treatment, vaccine, and consultation details
- Record weight, height, and age of child

### 📊 Reporting System
- Generate vaccination reports
- Generate medication reports
- Mask sensitive medical information for privacy
- Save reports to external `.txt` files

### 🧾 Record Management
- Update child records
- Delete child records
- View consultation history
- Maintain full audit trail of changes

### 🔔 Validation & Security
- Input validation for dates and numeric fields
- Basic authentication system
- Structured file storage using CSV

---

## 🛠️ Technologies Used
- C++ (Object-Oriented Programming)
- File Handling (`fstream`)
- STL (Vectors, Strings, Regex)
- Console-based UI
